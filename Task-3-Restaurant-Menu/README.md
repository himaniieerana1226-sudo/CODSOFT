# 🌸 Blossom – Floral Dining Restaurant Menu

## 📖 Overview
Blossom is a modern and elegant restaurant menu website inspired by floral aesthetics. The project showcases a beautifully designed digital menu with categorized dishes, smooth navigation, responsive layout, and a visually appealing user experience.

The website is designed to provide customers with an interactive menu browsing experience while highlighting the restaurant's unique floral theme and signature dishes.

---

## ✨ Features

- 🌸 Beautiful floral-inspired UI design
- 🍽️ Categorized menu sections (Starters, Soups, Mains)
- 📱 Fully responsive design for mobile and desktop
- 🎨 Modern typography and color palette
- 💰 Item pricing display
- 🏷️ Food tags (Vegetarian, Vegan, GF, Chef's Pick)
- ⚡ Smooth navigation between menu categories
- 📋 Professional restaurant-style menu layout

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Responsive Web Design
